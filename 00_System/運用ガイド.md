# Obsidian × Claude 運用ガイド

## 🔑 核心：なぜObsidianが「第二の脳」になるか

Claudeはセッションをまたいで記憶を持ちません。
でもObsidianにコンテキストを蓄積して毎回渡せば、
**Claudeは「あなたのことを知っている賢いパートナー」として機能します。**

---

## 📋 おすすめObsidianプラグイン

### コアプラグイン（標準搭載・ONにする）
| プラグイン | 用途 |
|---|---|
| テンプレート | `05_Templates/` のテンプレートを素早く挿入 |
| デイリーノート | 日次のメモ・ログ起点 |
| バックリンク | ノート間のつながりを可視化 |
| タグペイン | タグで知識を横断検索 |

### コミュニティプラグイン（おすすめ）
| プラグイン | 用途 |
|---|---|
| **Dataview** | ノートをデータベース的にクエリ・一覧化 |
| **Templater** | テンプレートに動的な日付・変数を埋め込む |
| **Calendar** | デイリーノートをカレンダーUIで管理 |
| **QuickAdd** | ホットキーでテンプレートから即ノート作成 |
| **Tag Wrangler** | タグの一括リネーム・管理 |

## ⚙️ おすすめ設定

### ファイル・リンク
- 新規ノートの保存場所 → `指定したフォルダ` → `04_Logs`
- 添付ファイルの保存先 → `現在のファイルと同じフォルダ内のサブフォルダ` → `_assets`
- リンク形式 → `短いパス`（Wikiリンク）

### テンプレート設定
- テンプレートフォルダ → `05_Templates`
- 日付形式 → `YYYY-MM-DD`

### テーマ
- 好みで。`Minimal` や `Things` が情報整理に向いている。

## 🔄 日々の運用フロー

```
【朝】
デイリーノートを開く → 今日の目標・やることを書く

【Claudeに相談するとき】
1. 関連プロジェクトノートを開く
2. 「Claudeへの相談メモ」セクションをコピー
3. 「私について.md」の内容もコピー
4. Claudeに貼り付けて会話スタート

【会話後】
1. 会話ログテンプレートで記録
2. 重要な学びは知識ノートに昇格
3. アクションはプロジェクトノートに追記

【週次レビュー】
- 04_Logs を振り返る
- 03_Knowledge に移すべきものがないか確認
- プロジェクトの進捗確認
```

## 💡 Claudeに渡すコンテキストの作り方

### 基本パターン（会話冒頭に貼る）

```
【私について】
（01_Claude_Profile/私について.md の内容）

【今回の相談】
（目的・背景を2〜3文で）

【関連する過去の決定事項】
（プロジェクトノートの「前回決めたこと」）

【お願い】
（指示書テンプレートから適切なものを選んで貼る）
```

### ポイント
- コンテキストは **長すぎず、短すぎず**。500〜1000文字が目安。
- 「前回決めたこと」を必ず含める → Claudeが一貫した提案をしやすくなる
- 「やってほしくないこと」も書くと精度が上がる
