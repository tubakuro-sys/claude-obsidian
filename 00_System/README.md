# この保管庫について

この保管庫は **Claudeとの対話を通じて育てる「第二の脳」** です。

## フォルダ構成

| フォルダ | 役割 |
|---|---|
| `00_System` | 運用ルール・構成メモ（このフォルダ） |
| `01_Claude_Profile` | Claudeに渡すプロフィール・指示書（旧版） |
| `02_Projects` | 進行中のプロジェクト単位のノート |
| `03_Knowledge` | 学んだこと・調査結果・永続知識 |
| `04_Logs` | 会話ログ・日次メモ・アーカイブ |
| `05_Templates` | テンプレート集 |
| `06_Memory` | ★ Claudeのメモリーコア（最重要） |
| `07_Mistakes` | ミス・反省の集約 |
| `08_Rules` | 自分ルール集 |

## 基本思想

- **Claudeはセッションをまたいで記憶を持たない**。だからObsidianが「記憶」を担う。
- `06_Memory/` の核心ファイルをClaudeが毎回自動で読むことで、前回の続きから動ける。
- ノートを育てるほど、Claudeとの対話精度が上がる。

## 運用フロー

1. 会話開始 → Claudeが `06_Memory/MEMORY_CORE.md` と `CURRENT_STATUS.md` を自動読み込み
2. 会話中 → 気づき・決定事項をメモ
3. 会話後 → `04_Logs/Daily/` にデイリーログ、`03_Knowledge/` に永続知識を保存
