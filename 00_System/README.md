# この保管庫について

この保管庫は **Claudeとの対話を通じて育てる「第二の脳」** です。

## フォルダ構成

| フォルダ | 役割 |
|---|---|
| `00_System` | 運用ルール・構成メモ（このフォルダ） |
| `01_Claude_Profile` | Claudeに渡すプロフィール・コンテキスト |
| `02_Projects` | 進行中のプロジェクト単位のノート |
| `03_Knowledge` | 学んだこと・調査結果・永続知識 |
| `04_Logs` | 会話ログ・日次メモ |
| `05_Templates` | テンプレート集 |

## 基本思想

- **Claudeはセッションをまたいで記憶を持たない**。だからObsidianが「記憶」を担う。
- 会話の前に関連ノートを貼り付けることで、Claudeは「前回の続き」として動ける。
- ノートを育てるほど、Claudeとの対話精度が上がる。

## 運用フロー

1. 会話前 → `01_Claude_Profile/私について.md` をコピペしてClaudeに渡す
2. 会話中 → 気づき・決定事項をメモ
3. 会話後 → `04_Logs` に要約を保存、`03_Knowledge` に永続知識を移す
