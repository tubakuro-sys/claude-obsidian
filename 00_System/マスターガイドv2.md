## 🔄 日々の運用フロー

### 朝（5分）
1. `04_Logs/Daily/YYYY-MM-DD.md` を新規作成（テンプレートから）
2. 今日のフォーカスを1〜3個書く
3. `CURRENT_STATUS.md` を30秒見直す

### Claudeに相談するとき
```
「MEMORY_COREとCURRENT_STATUSを読んで。
今日の相談は〇〇です。」
```
→ Claudeが自動でファイルを読んでコンテキストを把握する

### 会話後（3分）
1. デイリーログの「Claudeとの会話メモ」に要点を記録
2. ミスや反省 → `MISTAKES_LOG.md` に追記
3. 重要な気づき → `INSIGHTS.md` に追記
4. ルールの更新 → `RULES.md` に追記

### 週次レビュー（15分）
1. `MEMORY_CORE.md` の「現在の優先事項」を更新
2. `CURRENT_STATUS.md` を最新状態に更新
3. `07_Mistakes/` を振り返って傾向を確認
4. `03_Knowledge/` に昇格できる学びがないか確認

## 📦 おすすめObsidianプラグイン設定

### 必須（コアプラグイン）
| プラグイン | 設定 |
|---|---|
| デイリーノート | 保存先：`04_Logs/Daily`、テンプレート：`05_Templates/デイリーログ.md` |
| テンプレート | フォルダ：`05_Templates`、日付形式：`YYYY-MM-DD` |
| タグペイン | ON |
| バックリンク | ON |

### 強く推奨（コミュニティ）
| プラグイン | なぜ必要か |
|---|---|
| **Templater** | デイリーログに自動で日付・曜日を挿入 |
| **Dataview** | `#進行中` のプロジェクトを自動一覧化 |
| **Calendar** | デイリーログをカレンダーで管理 |
| **QuickAdd** | ミス記録・気づきをホットキーで即メモ |

### Dataviewの活用例（コピペで使える）

**進行中プロジェクト一覧**
````
```dataview
TABLE file.mtime AS "最終更新"
FROM "02_Projects"
WHERE contains(tags, "進行中")
SORT file.mtime DESC
```
````

**最近のミス一覧**
````
```dataview
LIST
FROM "07_Mistakes"
SORT file.ctime DESC
LIMIT 10
```
````

## 💡 Obsidian運用の黄金ルール

1. **完璧を求めない**　→ 短くても毎日書く方が価値がある
2. **リンクを張る**　→ `[[]]` でつなぐことで知識がネットワーク化される
3. **タグは少なく**　→ 増やしすぎると管理不能になる。上記のタグ設計を守る
4. **書くより読む**　→ 週次レビューで過去ノートを読み返すことが重要
5. **Claudeに整理させる**　→ 散らかったメモをClaudeに渡して「整理して」と頼む
