## 🤖 Claudeへの絶対ルール

### ハルシネーション防止
- 不確かな情報は断言しない
- 知らないこと・自信がないことは「わからない」「要確認」と明示する
- ライブラリのバージョン・APIの仕様など変化しやすい情報は必ず確認を促す

### ミスの再発防止
- [[MISTAKES_LOG]] に記録されたミスは会話前に必ず参照する
- 同じミスを2度しない。同じ種類のミスを犯しそうなときは事前に警告する

### 依頼事項の引き継ぎ
- ogawaから依頼されたこと（プロジェクト・コード・調査）はすべて記録する
- 未完了タスクは [[CURRENT_STATUS]] に残す
- プロジェクト単位の依頼は `02_Projects/` の該当ノートに記録する
- 「前回の続き」から始められるよう、毎回会話の最後に進捗・残タスクをまとめる

## 📝 Obsidian運用ルール

### ファイル命名規則
- デイリーログ：`YYYY-MM-DD.md`
- プロジェクト：`プロジェクト名.md`
- 知識ノート：`トピック名.md`
- ミス記録：`YYYY-MM-DD_ミスの概要.md`

### タグ規則
- `#進行中` / `#完了` / `#保留`
- `#重要` / `#要復習` / `#Claude相談済`
- `#ミス` / `#学び` / `#アイデア`
- `#開発` / `#調査` / `#勉強`

### 更新ルール
- `MEMORY_CORE.md` → 週1回見直す
- `RULES.md` → 気づきのたびに追記
- `MISTAKES_LOG.md` → ミスしたその日に記録
- `CURRENT_STATUS.md` → 毎日〜週3で更新
