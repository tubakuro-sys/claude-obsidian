# 2026-07-08（水）

## ループキャンディ（Loop Candy Puzzle）— GitHub公開＆広告動画のバグ修正

詳細は [[ループキャンディ]] を参照。

### 完了したこと
- **GitHub公開** ✅
  - `gh` CLI・`ffmpeg` をwingetでインストール、`gh auth login`でGitHubアカウント認証
  - リポジトリ `loop-candy-puzzle` を作成しpush、GitHub Pages有効化
  - 公開URL：https://tubakuro-sys.github.io/loop-candy-puzzle/
- **push.bat 作成** ✅
  - add→commit→push を1クリック化（日本語＋chcp 65001の組み合わせで文字化けし誤動作 → 英語表記に変更して解決）
- **広告動画が流れないバグ修正** ✅
  - 原因：固定ファイル名 `ad.mp4` を探しに行っていたが実ファイル名と不一致で即スキップされていた
  - 実際の動画3ファイルからランダム再生する方式に修正
- **音声が出ない／動画がラグい問題の修正** ✅
  - 音声：`muted`属性を外し、音声あり自動再生→ブロック時はミュート→それでもダメなら手動再生ボタン、の3段フォールバック
  - ラグ原因1：動画が1080p/14〜18Mbpsの高ビットレート → ffmpegで720p/2〜4Mbpsに再エンコードし大幅軽量化
  - ラグ原因2：広告再生中も裏でCanvas描画ループが動き続けていた → 広告再生中は描画を停止するよう修正
  - ローカル確認後、コミット・push・Pages反映まで完了

### メモ・気づき
- `.bat`ファイルに日本語プロンプトを書く場合、`chcp 65001`との組み合わせでcmdがバッチ内容を誤って読み直し文字化けする既知の問題がある → 日本語が必要ない箇所は英語表記にするのが手っ取り早い
- 広告動画のような自動再生は、ユーザーが既にページ上で操作済みであれば「音声あり自動再生」がブラウザにブロックされにくい（sticky user activation）
- 見えない場所（オーバーレイの裏）でも描画ループを止めない実装は、他の処理（動画デコード等）とCPU/GPUを取り合ってパフォーマンス問題を起こしうる
