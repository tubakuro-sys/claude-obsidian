# Frostlight — 凍てつく灯火

> 個人開発のオリジナル・サバイバル都市経営ゲーム。
> ステータス：🔧 プロトタイプ完成（越冬モード）／改修フェーズへ
> 作成開始：2026-07-09

---

## 🎮 概要

- **ジャンル**：ターン制サバイバル都市経営（Frostpunk 系だが世界観・システムは完全オリジナル）
- **形態**：単一HTMLファイル（インラインCSS+JS、外部依存はGoogle Fontsのみ）
- **対象**：まずは自分が本気で遊べる完成度。将来的に itch.io 無料公開／Steam も視野
- **プレイ時間**：1周 70日（ターン）

## 🌏 世界観

- 「大凍結（The Long Freeze）」後の凍てついた世界
- プレイヤーは最後の避難所 **終幕の炉（Lasthearth）** の **灯守（Warden）**
- 中央の熱源＝**胎炉（Core Hearth）**。これが消えれば全員凍死
- 資源5種：薪木 / 礫石 / 鋼片 / 保存食 / 炉炭　＋ 知識

## 📝 レビューで判明した課題（優先順）

### 第一段階：経済の嘘を消す ← **最重要・ここでしか面白さは生まれない**
- [ ] **リングの断熱が全体に効いている** → その環に住む者だけに効かせる（外環に建てて誰も住まわせない抜け道がある）
- [ ] **混焼が死に選択肢** → 燃料3択を本当の3択にする（薪は枯れる／炭は貯めた分だけ／混焼に固有の利点）
- [ ] **熟練度が選択になっていない** → 職ごとに固定し、配置換えで失われるようにする
- [ ] **イベントの選択肢に明らかな正解がある** → 「両方が痛い」ものだけ残す
- [ ] **大寒波の9夜が儀式でしかない** → 一夜ごとに決断を差し込む
- [ ] 希望・不満がその日の判断で動かない（法令パッシブで自動決定）

> ⚠️ この段階では絵も音も一切追加しない。灰色の四角のまま面白いか判定する。

### 第二段階：手触り
- [ ] **音**（最大の投資対効果）— 炉のうなり、吹雪、報告が開く音。freesound.org (CC0) / Kenney.nl
- [ ] **間** — 「夜を迎える」→暗転→報告が一行ずつ現れる／数字のカウントアップ
- [ ] **絵** — 炉の一枚絵、住民のシルエット、章ごとの背景

### 第三段階：包む
- [ ] Tauri でデスクトップアプリ化
- [ ] itch.io に無料/投げ銭で公開
- [ ] 5人に**説明せずに**渡してテスト

## 🛠 技術方針（2026-07-10 決定）

- **エンジン移植はしない。今のHTML/CSS/JSのまま進める**
  - 理由1：移植に2ヶ月かかるが、その間ゲームは1ミリも面白くならない
  - 理由2：弱点（経済の嘘・選択の浅さ）はエンジンを変えても直らない
  - 理由3：Frostlight は9割がUI。HTML/CSS/JS はUI構築で最速
- 配布は **Tauri**（Rust製・軽量・数MB）でラップ。Electron は100MB超なので避ける
- Godot への移植は「中身が完成して技術的に詰まったら」検討（おそらく詰まらない）

### 参考：エンジンの比較（2026-07-10 調査）
| | Unity | Godot |
|---|---|---|
| 費用 | 直近12ヶ月の収益・調達 20万USD 未満なら **Personal 無料** | 完全無料・永久（MIT） |
| ロイヤリティ | なし（Runtime Fee は撤回済み） | なし |
| 収益制限 | 20万USD 超で Pro（$2,040〜2,400/席・年） | なし |
| 機能制限 | Personal と Pro でエンジン機能差なし | — |
| 2D / UI | 良い | より良い |
| Switch/PS/Xbox | **Pro 必須** | 移植業者経由 |
| PC/スマホ/Web | 無料のまま出せる | 無料 |
