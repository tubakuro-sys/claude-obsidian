# 📋 アプリ仕様書

## 基本コンセプト

iPhoneのあすけんアプリ風のカロリー管理ツール。1つのHTMLファイルで完結し、スマホのホーム画面に追加してアプリのように使う。

## 🏗 画面構成（6タブ）

### 1. ホームタブ 🏠
- 摂取kcalのリング型ゲージ（目標到達で緑→赤）
- 目標・残り・消費kcalの数値表示
- 炭水化物・たんぱく質・脂質の達成率プログレスバー
- 塩分のプログレスバー
- 朝食・昼食・夕食・間食の食事カード（展開可能）
- 各食品の削除ボタン

### 2. 入力タブ ✏️
- よく使う食品のクイック選択チップ
- 手入力フォーム（食品名・kcal・単位・栄養素・食事タイミング・数量）
- 「よく使う食品に保存」チェックボックス
- 記録日表示（過去日に切り替えると反映）

### 3. マイセットタブ ⭐
- よく食べる組み合わせの保存（例：朝のルーティン）
- ワンタップでまとめて記録
- 最近使った食品リスト
- 食品を選んでセット作成モーダル

### 4. レシピタブ 🍳
- 現在の残り栄養素の表示
- リアルタイム栄養アドバイス（不足・過多を自動診断）
- スマート提案エンジン（6モード）
  - バランス重視・低カロリー・高たんぱく・糖質オフ・減塩・間食
- 食材から検索
- 過去7日間の栄養分析
- オリジナルレシピ追加機能
- レシピ詳細モーダル（食材・作り方・予測栄養）

### 5. 分析タブ 📊
- 今週のカロリー棒グラフ（タップで日付選択）
- 栄養バランス円グラフ（過去7日間の平均）
- 栄養素トレンド折れ線グラフ（Chart.js使用）
- 週間サマリー（平均kcal・累計・目標超過日数）

### 6. 設定タブ ⚙️
- サーバー連携設定（URL・ユーザーID）
- カロリー目標（kcal・消費kcal）
- マクロ栄養素目標（炭水化物・たんぱく質・脂質・塩分）
- データ管理（日付リセット・全リセット）
- よく使う食品の管理
- レシピDB管理

## 📅 日付指定機能

- 画面右上の「📅 今日」ボタン
- カレンダー型ピッカー（記録あり日は緑ドット表示）
- 過去日の閲覧・編集・追加が可能
- 分析タブの棒グラフタップでも日付ジャンプ
- 未来日は選択不可

## 💾 データ保存（localStorage）

| キー | 内容 |
|---|---|
| `cf_cfg` | 設定（目標値） |
| `cf_meals_YYYY-MM-DD` | 日付ごとの食事記録 |
| `cf_savedFoods` | よく使う食品リスト |
| `cf_mysets` | マイセット |
| `cf_recent` | 最近使った食品 |
| `cf_customRecipes` | オリジナルレシピ |
| `cf_serverCfg` | サーバー連携設定 |

## 🌐 サーバー連携モード（ハイブリッド構造）

- サーバーURL＋ユーザーIDを設定するとサーバー同期モード
- 未設定なら従来通りlocalStorageのみ
- 画面右上のバッジでモード表示（📱 ローカル / 📡 サーバー）

サーバーAPI仕様：
- `GET /health` - ヘルスチェック
- `GET /meals/:userId/:date` - 食事データ取得
- `PUT /meals/:userId/:date` - 食事データ保存
- `GET /meals/:userId` - 全データ取得
- `DELETE /meals/:userId/:date` - 削除
