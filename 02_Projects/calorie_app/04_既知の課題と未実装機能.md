### AIに投げる用のコピペできるテキスト機能（実装途中）

ユーザー要望：「AIに投げる用のコピペできるテキストはほしいかも」

**ステータス：実装開始したが完了せず**

#### 仕様

レシピタブに「📋 AIに相談用テキストをコピー」ボタンを追加する。
ボタンを押すと、以下のようなテキストがクリップボードにコピーされる：

```
【今日の栄養状態】
摂取済みkcal：450 / 目標2000kcal
残りkcal：1550
残り炭水化物：195g / たんぱく質：61g / 脂質：65g

【今日の食事記録】
朝食：白米（茶碗1杯）×1

上記の栄養状態を踏まえて、残りのカロリーと栄養素のバランスを補う夕食レシピを3つ提案してください。
```

ユーザーはこのテキストをコピー後、claude.ai や ChatGPT に貼り付けて使う。

#### 実装場所

[[02_技術スタック#フロントエンド|calorie_app.html]] のレシピタブ。
具体的には `<div id="sec-recipe">` の中の「📚 レシピデータベース」カードの前あたりに追加。

#### 追加すべきJS

```javascript
function buildAIPrompt(mode){
  const t=getTotals();
  const log=Object.entries(meals).filter(([,v])=>v.length).map(([m,v])=>`${m}：${v.map(f=>`${f.name}×${f.qty}`).join('、')}`).join('\n');
  const ctx=`【${currentDate}の栄養状態】\n摂取済みkcal：${Math.round(t.kcal)} / 目標${cfg.kcal}kcal\n残りkcal：${Math.max(0,Math.round(cfg.kcal-t.kcal))}\n残り炭水化物：${Math.max(0,Math.round(cfg.carb-t.carb))}g / たんぱく質：${Math.max(0,Math.round(cfg.prot-t.prot))}g / 脂質：${Math.max(0,Math.round(cfg.fat-t.fat))}g\n${log?'【食事記録】\n'+log:'（まだ食事の記録なし）'}`;
  const PROMPTS={
    balance:`${ctx}\n\n上記の栄養状態を踏まえて、残りのカロリーと栄養素のバランスを補う夕食レシピを3つ提案してください。各レシピは食材・作り方・カロリーを記載してください。`,
    lowcal:`${ctx}\n\n上記の栄養状態を踏まえて、低カロリーで満足感のあるレシピを3つ提案してください。`,
    highprot:`${ctx}\n\nたんぱく質を効率よく摂れるレシピを3つ提案してください。`,
    tonight:`${ctx}\n\n今夜の夕食メニューを3パターン提案してください。`,
    week:`${ctx}\n\n来週1週間の食事プランを提案してください。`,
  };
  return PROMPTS[mode]||PROMPTS.balance;
}

async function copyAIPrompt(mode){
  const text=buildAIPrompt(mode);
  try{
    await navigator.clipboard.writeText(text);
    toast('📋 コピーしました！claude.ai等に貼り付けてください');
  }catch(e){
    // フォールバック
    const ta=document.createElement('textarea');
    ta.value=text;ta.style.cssText='position:fixed;top:0;opacity:0';
    document.body.appendChild(ta);ta.select();document.execCommand('copy');document.body.removeChild(ta);
    toast('📋 コピーしました！');
  }
}
```

## 🐛 未解決の課題

### 1. 食材検索の表記ゆれ
「鶏むね肉」と「鶏胸肉」が別物として認識される。漢字/かなマッチング強化が必要。

### 2. レシピのバリエーション不足
標準レシピ30件はユーザーの食生活パターンに合わない可能性。
→ 自作レシピを促進するUI改善が必要。

### 3. 栄養目標の個人差
性別・年齢・活動量に応じた自動目標値計算がない。
→ 初回起動時に質問する設定ウィザード追加を検討。

### 4. データのバックアップ・エクスポート
localStorageの内容をJSONエクスポート/インポートする機能がない。
端末買い替え時にデータが移行できない。

### 5. 食事写真記録
画像アップロード機能がない（カメラAPIで実装可能）。
