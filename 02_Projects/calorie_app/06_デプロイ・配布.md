# 🚀 デプロイ・配布

## 📱 スマホで使う3つの方法

### 方法A：Netlify Drop（最速・推奨）

1. PCまたはスマホで [https://app.netlify.com/drop](https://app.netlify.com/drop) を開く
2. Googleアカウントでログイン（無料）
3. `calorie_app.html` を `index.html` にリネーム
4. ドラッグ＆ドロップ
5. 発行されたURL（例 `https://xxxxx.netlify.app`）をスマホで開く

### 方法B：GitHub Pages

1. [github.com](https://github.com/) でアカウント作成
2. リポジトリ作成（Public）
3. `index.html` をアップロード
4. Settings → Pages → Source: `main` → Save
5. `https://[ユーザー名].github.io/[リポジトリ名]/` でアクセス

### 方法C：自宅サーバー

`server.js` を Node.js で起動：

```bash
npm init -y
npm install express cors
node server.js
```

`http://localhost:3000` でアクセス。

## 📱 スマホ「ホーム画面に追加」手順

### iPhone（Safariで）
1. URLを Safari で開く
2. 共有ボタン（↑）
3. 「ホーム画面に追加」
4. 名前を入力 → 追加

### Android（Chromeで）
1. URLを Chrome で開く
2. メニュー（︙）
3. 「ホーム画面に追加」または「アプリをインストール」

## 🌐 サーバー同期モードの設定

家族間共有・複数端末同期する場合のみ。

1. サーバー（`server.js`）を起動
2. アプリの設定タブ → サーバー連携
3. サーバーURL: `http://[サーバーIP]:3000`
4. ユーザーID: 任意の名前
5. 「サーバー接続テスト」でOK確認
6. 画面右上のバッジが 📡 サーバー に変わる

### インターネット公開する場合

- VPS（さくら、AWS等）にserver.jsをデプロイ
- ngrokで一時公開：`ngrok http 3000`
- Render / Railwayなど無料PaaSで運用

### セキュリティ注意

- 現状はノーセキュリティ実装。誰でもユーザーIDがわかればアクセス可能
- 本番運用時はBasic認証やJWT認証を追加すべき
