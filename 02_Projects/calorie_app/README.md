## 🎯 プロジェクトゴール

- iPhone・Androidで使える1ファイル完結型のカロリー管理アプリ
- localStorageによる完全ローカル動作（プライバシー保護）
- 将来サーバー連携可能なハイブリッド構造
- AI API不要のルールベース提案エンジン

## ✅ 現在のステータス

**v5（ルールベース提案エンジン版）完成**

AIなしで完全動作するスマートレシピ提案機能を実装済み。
次回はAI連携用プロンプトコピー機能を追加予定（途中作業）。
