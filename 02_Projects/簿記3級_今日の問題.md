# 簿記3級 今日の問題

## 概要

「今日の問題」と入力すると起動する、簿記3級の対話型学習クイズアプリ。
Claude APIを使ったReactコンポーネント（Claudeアーティファクト内で動作）。

---

## 起動方法

チャットで `今日の問題` と入力する。

---

## 機能

- 問題数を選択（3 / 5 / 10 / 15問）
- 問題種別：仕訳・選択・計算・用語
- 1問ずつ対話形式で出題
- 回答後に正解/不正解 + 解説を表示
- 全問終了後に採点結果・正答率・ランクを表示

## ランク基準

| 正答率 | ランク |
|---|---|
| 90%以上 | 🏆 優秀！ |
| 70%以上 | ✅ 合格圏内 |
| 50%以上 | 📚 もう少し |
| 50%未満 | 💪 要復習 |

---

## 技術仕様

- **フレームワーク**：React（Claudeアーティファクト）
- **AIモデル**：claude-sonnet-4-20250514
- **API**：Anthropic /v1/messages
- **スタイル**：インラインCSS（ダークテーマ / グラデーション背景）
- **状態管理**：useState（setup / quiz / done の3フェーズ）
- **会話履歴**：messages配列でコンテキストを保持

## システムプロンプト設計

- 役割：簿記3級の試験官
- 出力：必ずJSONのみ（type: question / feedback / result）
- 問題タイプをJSONで返し、UIが動的にレンダリング
